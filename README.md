# تقرير حضور اجتماعات القطاعات

موقع تقرير رسمي (يوليو – أكتوبر 2026).

## النشر على GitHub Pages
1. ارفع كل محتويات المجلد إلى مستودع جديد (index.html في الجذر).
2. من Settings ثم Pages اختر الفرع main والمجلد root.
3. افتح الرابط الذي يظهر بعد دقيقة.

## الملفات
- index.html: الصفحة الكاملة
- elsayed.jpg: صورة معد التقرير
- images/: صور الموقع
